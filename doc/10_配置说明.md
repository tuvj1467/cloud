# 10 配置说明

> 本文是全部配置项的权威参考。配置结构体定义见 `cloud/internal/config/config.go`，所有业务键均为 `optional`（缺省时使用代码内默认值）。

## 一、核心服务：`cloud/etc/storage.yaml`

### 1. 服务基础（go-zero `zrpc.RpcServerConf` 内嵌）

| 键 | 示例值 | 说明 |
| -- | ------ | ---- |
| `Name` | `storage.rpc` | 服务名 |
| `ListenOn` | `0.0.0.0:8081` | gRPC 监听地址 |
| `Mode` | `dev` | `dev` 启动时自动执行存量数据迁移并输出开发日志；生产用 `prod` |
| `Etcd` | （注释掉） | 服务注册发现，单机直连场景不需要，网关用 IP 直连 |

### 2. MySQL

| 键 | 开发默认值 | 说明 |
| -- | ---------- | ---- |
| `MySQL.Host` | `127.0.0.1:3306` | 连接地址（IP:端口） |
| `MySQL.User` | `root` | 用户名（生产建议最小权限业务账号） |
| `MySQL.Password` | `12345` | ⚠ 开发默认值，生产必须修改 |
| `MySQL.Database` | `cloud` | 库名（utf8mb4） |
| `MySQL.Charset` | `utf8mb4` | 字符集（支持 emoji） |
| `MySQL.MaxOpenConns` | `100` | 最大打开连接数 |
| `MySQL.MaxIdleConns` | `20` | 最大空闲连接数 |
| `MySQL.ConnMaxLifetime` | `3600` | 连接最大存活时间（秒） |
| `MySQL.ConnMaxIdleTime` | `600` | 连接最大空闲时间（秒） |
| `MySQL.Debug` | `true` | 打印 SQL；生产必须 `false` |
| `MySQL.Loc` | `Local` | 时区 |

### 3. Redis

| 键 | 开发默认值 | 说明 |
| -- | ---------- | ---- |
| `RedisConf.Host` | `127.0.0.1:6379` | 连接地址 |
| `RedisConf.Password` | 空 | 密码（生产建议设置） |
| `RedisConf.DB` | `0` | 逻辑库编号 |
| `RedisConf.PoolSize` | `50` | 连接池大小 |

> Redis 中的键设计（秒传索引 / 分片状态 / 分享缓存）见 [03_数据库设计.md](03_数据库设计.md)。

### 4. 存储驱动

| 键 | 开发默认值 | 说明 |
| -- | ---------- | ---- |
| `Storage.Driver` | `local` | 驱动类型：`local`（MinIO/S3 接口已预留，见 [04_存储引擎设计.md](04_存储引擎设计.md)） |
| `Storage.Local.RootDir` | `./cloud_storage` | 本地存储根目录，物理文件按规则写入其下 |

### 5. JWT 鉴权

| 键 | 默认值 | 说明 |
| -- | ------ | ---- |
| `JWT.Secret` | `www.topgoer.com` | ⚠ 开发演示值，生产必须更换为 32+ 随机字符 |
| `JWT.Expire` | `604800` | token 有效期（秒），7 天 |
| `JWT.Issuer` | `127.0.0.1` | 签发者标识 |

> 白名单（免鉴权接口）不在配置文件中，硬编码于 `cloud/internal/middleware/jwt_middleware.go`。

## 二、HTTP 网关：`gateway/gateway.yaml`

### 1. 顶层

| 键 | 值 | 说明 |
| -- | -- | ---- |
| `Name` | `storage-gateway` | 网关名 |
| `Host` / `Port` | `0.0.0.0` / `8888` | HTTP 监听 |
| `Timeout` | `3000` | 请求超时（毫秒） |
| `Header` | `Authorization` | 鉴权 header 名，转发时映射为 gRPC metadata |

### 2. `upstreams`（当前仅一个上游 `storage.rpc`）

| 键 | 值 | 说明 |
| -- | -- | ---- |
| `Grpc.target` | `127.0.0.1:8081` | 核心 gRPC 服务地址（**容器部署时为 `cloud:8081`**） |
| `Grpc.schema` | `""` | go-zero 1.4+ 必填，空即可 |
| `ProtoSet` / `ProtoSets` | `protoset.pb` | proto 描述符集，网关据此做 REST↔gRPC 转换 |
| `Mappings[]` | 26 条 | REST 路由 → RPC 方法映射 |

### 3. 路由映射规则

```yaml
- Method: POST          # HTTP 方法
  Path: /user/register  # REST 路径
  RpcPath: storage.User/Register   # gRPC 全限定方法名
```

**本文件是 REST 路由的唯一真源**（共 26 条：文件 8、分片上传 4、文件分享 2、桶 5、用户 7），汇总表见根 [README.md](../README.md) 的「API 总览」。

**新增接口的同步步骤**：改 proto → 重新生成代码 → 重新生成 `protoset.pb`（命令见根 README「代码生成」）→ **同时**更新 `gateway/gateway.yaml` 与 `deploy/gateway/gateway.yaml`（两份必须保持一致）→ 重启网关。

## 三、Web 前端：`web/server.go` 启动参数

`go run server.go` 可带以下 flag：

| 参数 | 默认值 | 说明 |
| ---- | ------ | ---- |
| `-port` | `8080` | Web 监听端口 |
| `-api` | `http://localhost:8888` | 上游网关地址 |
| `-static` | `./` | 静态文件目录（index.html/css/js 所在） |

行为要点：

1. `/api/*` 反向代理到网关，其余路径走静态文件服务；
2. 代理时自动把 `Authorization` 请求头改写为 `Grpc-Metadata-Authorization`（gRPC 网关只会转发带该前缀的 header 到 metadata），前端因此可以按常规方式携带 token；
3. 自带 CORS 中间件，允许跨域调试。

> 注意：`web/server.go` 依赖仓库根目录的 `go.mod`（模块 `ONE_CLOUD`），请在仓库根目录执行 `go run web/server.go` 或参考 `web/Dockerfile`。

## 四、容器化配置：`deploy/`

Docker Compose 挂载的配置与本地版的差异**只有以下几点**，其余键位完全一致：

| 差异点 | 本地（cloud/etc、gateway/） | 容器（deploy/） |
| ------ | --------------------------- | ---------------- |
| MySQL/Redis 地址 | `127.0.0.1:3306` / `127.0.0.1:6379` | `mysql:3306` / `redis:6379`（compose 服务名） |
| 存储根目录 | `./cloud_storage` | `/data/cloud_storage`（挂载卷） |
| 服务模式 | `dev` | `prod` |
| SQL 调试 | `true` | `false` |
| 网关 gRPC 目标 | `127.0.0.1:8081` | `cloud:8081` |

数据库密码、Redis 密码、JWT Secret 需在 `deploy/cloud/storage.yaml` 与 `docker-compose.yml`（`MYSQL_ROOT_PASSWORD`）中保持一致，并在生产前统一更换。
