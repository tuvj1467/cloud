| 字段 | 类型 | 约束 | 说明 |

## 三、Bucket（存储桶）

### 3.1 字段（已存在，补充索引与关系）

| 字段 | 类型 | 约束 | 说明 |
| ---- | ---- | ---- | ---- |
| id | string | unique | 桶主键（雪花 ID） |
| name | string | - | 桶名称 |
| user_id | string | not empty | 所属用户 |
| description | string | optional | 桶描述 |
| size_limit | int64 | default 1GB | 容量上限（字节） |
| used_size | int64 | default 0 | 已用容量（字节） |
| visibility | enum | default private | private / internal / public |
| created_at / updated_at / version | - | - | mixin |

### 3.2 需补充的索引

```go
func (Bucket) Indexes() []ent.Index {
    return []ent.Index{
        // 同一用户下桶名唯一
        index.Fields("user_id", "name").Unique(),
        // 按用户查询高频
        index.Fields("user_id"),
    }
}
```

### 3.3 需补充的 Edges

```go
func (Bucket) Edges() []ent.Edge {
    return []ent.Edge{
        // 桶 → 文件（一对多）
        edge.To("files", File.Type),
    }
}
```

> 说明：`user_id` 与 Bucket 的关系不做 ent edge（user 表暂保持独立），通过字段关联查询。

## 四、File（文件）

### 4.1 字段（已存在）

| 字段 | 类型 | 约束 | 说明 |
| ---- | ---- | ---- | ---- |
| id | string | unique | 文件主键（雪花 ID） |
| name | string | - | 文件名 |
| ext | string | optional | 扩展名（如 jpg） |
| path | string | - | 存储路径（相对驱动根） |
| size | int64 | - | 文件大小（字节） |
| md5 | string | - | 文件 MD5 |
| content_type | string | - | MIME 类型 |
| bucket_id | string | - | 所属桶 ID |
| user_id | string | not empty | 所属用户 |
| created_at / updated_at / version | - | - | mixin |

### 4.2 需补充的索引

```go
func (File) Indexes() []ent.Index {
    return []ent.Index{
        // 同一桶下文件名唯一（防重名）
        index.Fields("bucket_id", "name").Unique(),
        // 用户维度查询
        index.Fields("user_id"),
        // 秒传查询
        index.Fields("md5", "user_id"),
    }
}
```

### 4.3 需补充的 Edges

```go
func (File) Edges() []ent.Edge {
    return []ent.Edge{
        edge.From("bucket", Bucket.Type).
            Ref("files").
            Field("bucket_id").
            Unique(),
    }
}
```

## 五、FilePart（分片上传记录）— 新增

用于断点续传，记录每个分片的上传状态。

| 字段 | 类型 | 约束 | 说明 |
| ---- | ---- | ---- | ---- |
| id | string | unique | 分片记录主键 |
| upload_id | string | not empty | 一次分片上传的唯一标识（雪花 ID） |
| file_id | string | optional | 关联文件（合并完成后写入） |
| user_id | string | not empty | 上传用户 |
| bucket_id | string | not empty | 目标桶 |
| part_number | int | - | 分片序号（从 1 开始） |
| part_size | int64 | - | 分片大小 |
| part_md5 | string | - | 分片 MD5 |
| part_path | string | - | 分片存储路径 |
| status | enum | default pending | pending / uploaded / merged |

### 5.1 索引

```go
index.Fields("upload_id", "part_number").Unique()
index.Fields("user_id")
```

## 六、FileShare（文件分享）— 新增

| 字段 | 类型 | 约束 | 说明 |
| ---- | ---- | ---- | ---- |
| id | string | unique | 分享记录主键 |
| file_id | string | not empty | 被分享的文件 |
| user_id | string | not empty | 分享发起人 |
| share_code | string | unique | 提取码（随机串） |
| permission | enum | default read | read / download |
| expire_at | *time | optional + nillable | 过期时间（nil=永久） |
| max_count | *int | optional + nillable | 最大访问次数（nil=不限） |
| used_count | int | default 0 | 已访问次数 |

> 说明：`expire_at` 与 `max_count` 使用 `.Optional().Nillable()` 双标记，确保 ent 生成指针类型，可区分 NULL（永久/不限）与零值。

### 6.1 索引

```go
index.Fields("share_code").Unique()  // 字段已 Unique，索引辅助查询
index.Fields("file_id")
index.Fields("user_id")
```

## 八、Redis 键设计

| Key 模式 | 类型 | 用途 | TTL | 实现位置 |
| -------- | ---- | ---- | --- | -------- |
| `md5:{user_id}:{md5}` | string | 秒传索引，value=file_id | 30 天 | [cache/md5_cache.go](../cloud/internal/pkg/cache/md5_cache.go) |
| `upload:{upload_id}:meta` | string(JSON) | 分片上传元信息（user/bucket/name/suffix/size/total_parts/storage_id） | 24 小时 | [cache/multipart_cache.go](../cloud/internal/pkg/cache/multipart_cache.go) |
| `upload:{upload_id}:parts` | hash | 已上传分片：field=part_number，value=part_md5 | 24 小时 | 同上 |
| `share:{code}:meta` | string(JSON) | 分享元信息（不含已用次数） | 与 expire_at 对齐，永久则 7 天 | [cache/share_cache.go](../cloud/internal/pkg/cache/share_cache.go) |
| `share:{code}:counter` | string(int) | 已用访问次数（INCR 原子递增） | 同上 | 同上 |
| `user:token:{user_id}` | string | 在线 token（可选，用于踢线） | 7 天 | 预留 |
| `bucket:used:{bucket_id}` | string | 桶已用容量缓存（热读） | 5 分钟 | 预留 |

## 九、数据迁移说明

1. **现有 File 数据**：`bucket_id` 为空，需提供迁移逻辑——为每个用户创建默认桶 `default`，将无桶文件归入
2. **迁移方式**：启动时检测，若 `File.bucket_id` 为空则执行迁移脚本（一次性）
3. **dev 模式**：`entClient.Schema.Create` 会自动建表/加字段，但不会自动建索引，需手动执行 migrate 或重建
4. **实现位置**：[pkg/migrate/migrate.go](../cloud/internal/pkg/migrate/migrate.go)，在 `main.go` 中 `c.Mode == "dev"` 时自动调用
5. **幂等性**：查询条件 `bucket_id == ""`，重复执行不会重复回填
