# 04 存储引擎设计

## 一、设计目标

将物理存储操作从业务逻辑中抽离，通过统一接口支持多后端切换：

- **本地磁盘**：开发环境默认，零依赖
- **MinIO**：自建对象存储，S3 兼容，生产推荐
- **S3 / OSS**：公有云对象存储（预留接口，后续实现）

切换方式：配置文件 `Storage.Driver` 字段，由 `ServiceContext` 在启动时注入对应实现。

## 二、目录结构

```
cloud/internal/pkg/storage/
├── driver.go          # Driver 接口定义
├── local_driver.go    # 本地磁盘实现
├── minio_driver.go    # MinIO/S3 实现（第二阶段）
└── factory.go         # 工厂函数，按配置返回实现
```

## 三、Driver 接口定义

```go
// Package storage 提供对象存储驱动抽象
package storage

import (
    "context"
    "io"
)

// Driver 存储驱动接口，所有后端必须实现
type Driver interface {
    // Put 上传完整文件（小文件）
    // path: 相对路径（如 user_id/20260727/file_id.jpg）
    Put(ctx context.Context, path string, reader io.Reader, size int64) error

    // Get 下载文件，返回可读流
    Get(ctx context.Context, path string) (io.ReadCloser, error)

    // Delete 删除文件
    Delete(ctx context.Context, path string) error

    // Stat 获取文件信息（大小、修改时间）
    Stat(ctx context.Context, path string) (*FileInfo, error)

    // Exists 判断文件是否存在
    Exists(ctx context.Context, path string) (bool, error)

    // InitPart 初始化分片上传，返回 upload_id
    InitPart(ctx context.Context, path string, totalParts int) (uploadID string, err error)

    // UploadPart 上传单个分片
    UploadPart(ctx context.Context, uploadID string, partNumber int, reader io.Reader, size int64) (partMD5 string, err error)

    // CompletePart 合并所有分片为完整文件
    CompletePart(ctx context.Context, uploadID string) error

    // AbortPart 取消分片上传，清理临时分片
    AbortPart(ctx context.Context, uploadID string) error

    // PresignURL 生成预签名 URL（直传/直下，MinIO/S3 适用）
    // 本地驱动返回空字符串与 notImplement 错误
    PresignURL(ctx context.Context, path string, expire int64, method string) (string, error)
}

// FileInfo 存储层文件信息
type FileInfo struct {
    Size         int64
    LastModified int64 // unix 秒
    ContentType  string
}
```

## 四、本地磁盘实现（`local_driver.go`）

```go
type LocalDriver struct {
    rootDir string
}

func NewLocalDriver(rootDir string) *LocalDriver {
    return &LocalDriver{rootDir: rootDir}
}

// Put 写入本地文件
func (d *LocalDriver) Put(ctx context.Context, path string, reader io.Reader, size int64) error {
    fullPath := filepath.Join(d.rootDir, path)
    if err := os.MkdirAll(filepath.Dir(fullPath), 0755); err != nil {
        return err
    }
    f, err := os.Create(fullPath)
    if err != nil {
        return err
    }
    defer f.Close()
    _, err = io.Copy(f, reader)
    return err
}

// Get 读取本地文件
func (d *LocalDriver) Get(ctx context.Context, path string) (io.ReadCloser, error) {
    return os.Open(filepath.Join(d.rootDir, path))
}

// Delete 删除本地文件
func (d *LocalDriver) Delete(ctx context.Context, path string) error {
    return os.Remove(filepath.Join(d.rootDir, path))
}
```

- 分片上传在本地实现中：`InitPart` 创建临时目录 `{root}/.tmp/{uploadID}/`，`UploadPart` 写入 `part_{N}`，`CompletePart` 拼接所有分片并移动到目标路径
- `PresignURL` 返回 `ErrNotImplemented`（本地不支持预签名）

## 五、MinIO 实现（`minio_driver.go`，第二阶段）

```go
type MinioDriver struct {
    client   *minio.Client
    bucket   string
}
```

- `Put` → `client.PutObject`
- `Get` → `client.GetObject`
- `Delete` → `client.RemoveObject`
- `InitPart` → `client.NewMultipartUpload`（MinIO 原生分片）
- `UploadPart` → `client.UploadPart`
- `CompletePart` → `client.CompleteMultipartUpload`
- `PresignURL` → `client.PresignedGetObject` / `PresignedPutObject`

## 六、工厂函数（`factory.go`）

```go
// NewDriver 根据配置返回存储驱动实例
func NewDriver(cfg StorageConf) (Driver, error) {
    switch cfg.Driver {
    case "local":
        return NewLocalDriver(cfg.Local.RootDir), nil
    case "minio":
        return NewMinioDriver(cfg.Minio)
    default:
        return nil, fmt.Errorf("不支持的存储驱动: %s", cfg.Driver)
    }
}
```

## 七、路径规范

存储路径统一格式：`{user_id}/{date}/{file_id}.{ext}`

- `user_id`：文件所属用户
- `date`：`YYYYMMDD`，按日期分目录便于归档
- `file_id`：雪花 ID
- `ext`：扩展名（无扩展名则省略）

分片临时路径：`.tmp/{upload_id}/part_{number}`

## 八、与 logic 层协作

logic 层不再直接调用 `os.*`，改为：

```go
// 上传（替换现有 upload_file_logic.go 中的 os.WriteFile）
err := l.svcCtx.Storage.Put(l.ctx, filePath, bytes.NewReader(in.Content), in.Size)

// 下载
reader, err := l.svcCtx.Storage.Get(l.ctx, file.Path)
defer reader.Close()
content, _ := io.ReadAll(reader)

// 删除
err := l.svcCtx.Storage.Delete(l.ctx, file.Path)
```

## 九、错误处理

新增存储错误码段（30xxx）：

| 码 | 含义 |
| -- | ---- |
| 30001 | 存储驱动初始化失败 |
| 30002 | 文件写入失败 |
| 30003 | 文件读取失败 |
| 30004 | 文件删除失败 |
| 30005 | 桶容量不足 |
| 30006 | 分片上传未完成 |
| 30007 | 分片校验失败 |
| 30008 | 不支持的操作（如本地驱动预签名） |

## 十、容量校验流程

上传前在 logic 层：

1. 查 Bucket 获取 `size_limit` 与 `used_size`
2. 判断 `used_size + file_size <= size_limit`，否则返回 `30005 桶容量不足`
3. 上传成功后，事务内更新 `used_size`：
   ```sql
   UPDATE bucket SET used_size = used_size + ?, version = version + 1
   WHERE id = ? AND version = ?
   ```
   version 不匹配则回滚重试（乐观锁）
4. Redis `bucket:used:{bucket_id}` 缓存失效
