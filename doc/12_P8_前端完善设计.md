## 三、功能覆盖（补齐 14 个缺失接口 + 完善已有 11 个）

### 3.1 认证（AuthPanel）

- Tab：账号登录 / 注册 / 重置密码
- 登录：账号密码（现有）；**手机验证码、邮箱验证码**（sendVerificationCode + loginByPhoneSms/EmailSms，倒计时 60s 按钮）
- 注册：账号注册（现有）；**手机/邮箱注册**（oneof 参数 + 必填 6 位验证码）；依赖第四节后端修复
- 重置密码：手机/邮箱 + 验证码 + 新密码（resetPassword，此前后端永久失败已修）
- 401（code 10101/10102）或 token 过期：清 store 回登录页，全局拦截

### 3.2 文件列表（FileList）

- 接口：getFileList / getBucketFileList（Tab 切换「全部文件 / 桶内文件」，桶下拉选择）
- 分页控件（page/page_size，后端真实分页）、文件名搜索（前端过滤当前页 + 后端无搜索接口的说明占位）、排序切换（name/size/create_time × asc/desc，后端已支持）
- 行操作：下载（用原始文件名）、重命名（rename）、复制（copy，弹窗选目标桶）、分享（ShareDialog）、删除（确认框）
- 展示：类型图标（按 ext 映射 emoji）、大小格式化（B/KB/MB/GB）、时间格式化；加载骨架屏、空状态文案

### 3.3 上传（UploadPanel）

- 目标桶下拉（必选，默认第一个桶）；拖拽 + 多选保留
- 单文件 ≤5MB：JSON base64 直传 uploadFile（XHR 以获得 upload.onprogress 字节级进度；FormData 网关实测拒绝）
- 单文件 >5MB：自动分片——initMultipartUpload 取 PartSize → 按 3 并发上传分片（uploadPart，逐片断点重试 1 次）→ completeMultipartUpload；AbortMultipartUpload 支持取消按钮；进度 = 已完成分片字节累计 / 总量
- 秒传命中（响应 instant=true）显示「秒传成功」标识
- 错误：30012 超限、10006 频率、20004 配额不足按错误码提示

### 3.4 文件分享（ShareDialog + SharePage）

- 创建：有效期（1/7/30 天/永久，映射 `expire_seconds`）、**下载次数上限**（可选，映射 `max_count`——P9 语义：仅 DownloadByShare 扣减，访问页查看不计次）、权限（read/download）；提取码由服务端生成（`share_code`），UI 纯展示 + 一键复制链接（`{origin}/#/share/{code}`）——后端不支持自定义提取码
- 访问页：匿名路由 `#/share/:code`，AccessShare → 文件信息（名称/大小/类型）+ **下载按钮**（走第五节新增的 `DownloadByShare`，匿名可下载；有效期与次数由后端校验）

### 3.5 桶管理（BucketPanel）

- 列表：名称、可见性、用量进度条（used_size/size_limit）、创建时间
- 创建（现有）；**信息**（getBucketInfo）、**更新**（updateBucket：描述/容量/可见性）、**删除**（deleteBucket，非空时提示并可勾选 force 强制删除）

## 四、API 客户端（api.js）

- `request(path, {method, params, body, raw})` 统一封装：fetch 透传 `Authorization: <token>`（web/server.go 已转 Grpc-Metadata-Authorization）；响应统一 `{code, message, data}` 解包
- 错误码 → 中文文案映射表（含 P7 新增：10006 发送过于频繁、10007 验证码服务不可用、30012 文件超限、40006 路径非法；以及 10004/10005 验证码错误/过期、20004 配额不足、30001-30022 文件与分享系列、10101-10103 token 系列）
- 特例：下载走 fetch+blob（拿 filename）；分片 uploadPart 直传 FormData
- 禁止 `v-html`（XSS 根治：Vue 插值默认转义）

## 五、后端配套（新增 1 个 RPC + 1 个逻辑小修）

1. **DownloadByShare**（决策 D7，用户确认）：匿名分享目前只能看不能下（`/file/download` 需 JWT）。
   - proto：`file.proto` 新增 `DownloadByShareRequest{string share_code}`，`service.proto` 的 File 服务新增 `rpc DownloadByShare`，返回形态**与现有 DownloadFile 完全对齐**（实施时以其实际签名/流式方式为准）；校验复用 AccessShare 链路（存在性/过期/次数扣减/permission=download），permission=read 的分享允许下载但记录权限
   - 白名单：`middleware/jwt_middleware.go` 公开方法加入该方法（匿名可访问）
   - 网关：`gateway.yaml` 与 `deploy/gateway/gateway.yaml` 同步新增 `GET /file/share/download?share_code=xxx`，重新生成 `protoset.pb`
   - 生成命令绕过 goctl 直接用 protoc（避免脚手架重建）：`protoc --go_out=. --validate_out=...` + `protoc --go-grpc_out=.` + protoset 描述符命令
2. **nickname fallback**：`cloud/internal/repository/user.go` 的 `CreateByPhone` / `CreateByEmail`——`name` 为空时用 `phone`/`email` 兜底（proto oneof 导致注册时 `in.GetName()` 恒为空，昵称 NotEmpty 校验拒绝创建）。约 4 行改动 + curl 验证手机号注册→手机验证码登录全链路。

## 六、验证策略

- 后端：`go build/test` 全绿；curl 验证手机号注册 → 发验证码 → 手机验证码登录 → 上传文件全链路
- 前端：browser-use 无头浏览器 GUI 冒烟清单：
  1. 账号注册 → 登录 → 401 过期自动登出
  2. 手机号注册（验证码走 cloud 日志取码）→ 手机验证码登录
  3. 小文件直传（进度条）→ 大文件分片上传（>5MB，观察分片与进度）→ 秒传重复上传
  4. 列表分页/排序/搜索 → 重命名 → 复制 → 下载（文件名正确）
  5. 创建分享 → 匿名窗口访问 #/share/:code → 下载
  6. 桶创建 → 更新 → 用量条展示 → force 删除
- XSS 回归：文件名含 `<script>`/`<img onerror>` 的用例上传后列表页确认转义
